Proyecto Final: FUNDAMENTOS DE PROGRAMACIÓN

DESCRIPCIÓN:

Este proyecto está desarrollado en Python y utiliza un archivo en formato JSON para su funcionamiento. El archivo JSON debe encontrarse 
en la misma carpeta que el archivo principal (Archivo_Final.py)

REQUISITOS:

Tener instalado:

* Visual Studio Code
* Python 3.x
* Git (Opcional si desea o no clonar el repositorio)

EJECUCIÓN:

1. Clona el repositorio en tu computadora o descarga los archivos Archivo_Final.py y datos_sistema.json desde Git.
2. Verifica que ambos archivos estén en la misma carpeta.
3. Abre el archivo 'Archivo_Final.py' desde Visual Studio Code
3. Dale click a ejecutar

CONSIDERACIONES:

*No cambies la ubicación del archivo JSON, ya que el programa espera encontrarlos en el mismo directorio que 'Archivo_Final.py'.
*Si no instala el JSON, el programa lo crea solo en la misma ruta en la que se encuentre 'Archivo_Final.py'.
*Se recomienda descargar el archivo datos_sistema.json, ya que contiene datos precargados para el programa.
